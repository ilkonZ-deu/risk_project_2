## PCA — снижение размерности (п. 2a)

### Кривая ставок (PCA по ковариации изменений)
| Компонента | Доля дисперсии | Накопл. | Интерпретация |

| PC1 | 76.1% | 76.1% | level (параллельный сдвиг) |

| PC3 | 6.5% | 95.7% | curvature (изгиб) |
| PC4 | 3.3% | 99.0% | (резерв) |

Форма нагрузок классическая (level — один знак, slope — смена знака, curvature — U-образная). PC1 перекошен в короткий конец из-за экстремальной волатильности коротких ставок в 2022/2024 — осознанный компромисс ради интерпретации в б.п.

### Акции (PCA по стандартизованным доходностям)
- PC1 = 62.4% — рыночный фактор, все нагрузки одного знака. Валидация: corr(PC1, IMOEX) = 0.862, corr(PC1, RTSI) = 0.709 (RTSI ниже — долларовый индекс).
- PC2 — отраслевой контраст (внутренние/телеком MTSS, CHMF, MGNT против нефтегаза LKOH, TATN, NVTK).
- PC3 — металлурги (GMKN, CHMF).
- Индивидуальные доходности сохранены для точного pricing.

## 1. Цель этапа

Основная цель – построить математическое описание эволюции каждого риск-фактора (см. `risk_factors.csv`), которое будет использоваться в дальнейшем для симуляции совместного распределения факторов при расчёте рыночного риска (VaR и ES). Требуется:

- Для каждого фактора выбрать подходящую стохастическую модель.
- Обосновать выбор на основе статистических свойств ряда (тяжесть хвостов, кластеризация волатильности, стационарность).
- Оценить параметры модели методом максимального правдоподобия (MLE) по всей доступной истории (2021–2025).

## 3. Выбор моделей

Выбор основывался на результатах предварительного анализа (описательная статистика, корреляции, тяжесть хвостов, стационарность, наличие кластеризации волатильности).

### 3.1. Факторы ставок (`RATE_PC1`–`RATE_PC3`)

- **Свойства:** стационарны, слабая автокорреляция, но значительная эксцессивная куртозис (тяжёлые хвосты). Кластеризация волатильности выражена слабо.
- **Выбор:** Сравнивались нормальное и t-распределение (Стьюдента) с использованием AIC. Для всех трёх факторов **t-распределение** показало лучшее AIC, поэтому выбрано именно оно.
- **Обоснование:** Учёт тяжёлых хвостов важен для корректной оценки экстремальных изменений ставок, особенно в кризисные периоды.

### 3.2. Факторы доходностей (акции, валюты, нефть)

- **Свойства:** стационарны, практически отсутствует автокорреляция самих доходностей, но ярко выражена кластеризация волатильности (автокорреляция квадратов). Хвосты распределений тяжелее нормальных.
- **Выбор:** Для каждого фактора подгонялась модель **GARCH(1,1)** с двумя вариантами распределения ошибок: нормальное и t-Стьюдента. Выбор между ними производился по минимальному AIC.
  - Для `r_GMKN`, `r_TATN`, `r_EUR` выбрана **GARCH-t** (параметр `nu` ≈ 5–6), что говорит о значительной тяжести хвостов.
  - Для остальных доходностей (`r_SBER`, `r_GAZP`, `r_LKOH`, `r_ROSN`, `r_NVTK`, `r_MGNT`, `r_MTSS`, `r_CHMF`, `r_USD`, `r_BRENT`) выбрана **GARCH-normal** (AIC оказался немного лучше, вероятно, из-за недостатка экстремальных наблюдений в обучающей выборке).
- **Обоснование:** GARCH(1,1) – стандартная модель для финансовых доходностей, хорошо описывающая динамику волатильности. Использование t-распределения там, где это статистически оправдано, повышает точность оценки хвостовых рисков.
