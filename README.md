## PCA — снижение размерности (п. 2a)

### Кривая ставок (PCA по ковариации изменений)
| Компонента | Доля дисперсии | Накопл. | Интерпретация |
|---|---|---|---|
| PC1 | 76.1% | 76.1% | level (параллельный сдвиг) |
| PC2 | 13.1% | 89.2% | slope (наклон) |
| PC3 | 6.5% | 95.7% | curvature (изгиб) |
| PC4 | 3.3% | 99.0% | (резерв) |

Форма нагрузок классическая (level — один знак, slope — смена знака, curvature — U-образная). PC1 перекошен в короткий конец из-за экстремальной волатильности коротких ставок в 2022/2024 — осознанный компромисс ради интерпретации в б.п.

### Акции (PCA по стандартизованным доходностям)
- PC1 = 62.4% — рыночный фактор, все нагрузки одного знака. Валидация: corr(PC1, IMOEX) = 0.862, corr(PC1, RTSI) = 0.709 (RTSI ниже — долларовый индекс).
- PC2 — отраслевой контраст (внутренние/телеком MTSS, CHMF, MGNT против нефтегаза LKOH, TATN, NVTK).
- PC3 — металлурги (GMKN, CHMF).
- Индивидуальные доходности сохранены для точного pricing.

## Описательная статистика и корреляции (п. 2c)

- Среднее всех факторов ≈ 0.
- Сильнейшие связи: USD↔EUR 0.916; нефтяной кластер (ROSN-TATN 0.763 и др.); банки↔нефть. RATE_PC слабо отрицательно связаны с акциями (ставки↑ → акции↓), что экономически корректно.

### Тяжесть хвостов
- Нормальность отвергнута у **16 из 16** факторов (Jarque-Bera p ≈ 0).
- Оценка степеней свободы Student-t: ≈ 1.9–3.7 (тяжёлые хвосты).
- Сильный отрицательный скос у акций (риск обвалов), особенно SBER (skew ≈ −6, exc.kurt ≈ 112) и ROSN.
- Q-Q графики: характерные загибы на хвостах.

### Кластеризация волатильности
Реализованная годовая волатильность SBER: 2021 — 25.8%, **2022 — 69.4%**, 2023 — 24.5%, 2024 — 24.2%, 2025 — 22.5%. Явный эффект ARCH.

## Оговорки по данным

1. **Сплит GMKN 100:1 (апрель 2024)** — скорректирован back-adjustment (искусственный −459% устранён, реальное движение дня +1.6% сохранено).
2. **FX: 23.1% нулевых приращений** из-за ffill официального курса ЦБ. Параметрический Student-t для валют мис-специфицирован → для VaR валютного подпортфеля рекомендована историческая симуляция или zero-inflated модель. В экспорт включены хвостовые оценки FX без нулей.
3. **Структурный сдвиг 2022** включён в выборку — для горизонта риска имеет смысл рассмотреть EWMA / режимное окно.
