# risk_project_2 — Сбор данных российского финансового рынка


## Что собрано 1 участником

| Пункт | Данные | 
|---|---|
| **1** | Кривая бескупонной доходности (КБД): ставки по 12 срокам 0.25–30 лет |
| **2** | Расписания выплат 5 ОФЗ (купоны + погашение номинала) | 
| **3** | Рыночные котировки 5 ОФЗ (цена закрытия) | 
| **3** | Котировки 5 ОФЗ — полные (доходность, дюрация, НКД) | 
| **4** | 10 ликвидных российских акций (цены закрытия) |
| **5** | Индексы МосБиржи (IMOEX) и РТС (RTSI) | 
| **5** | Курсы USD/RUB и EUR/RUB |
| **5** | Нефть Brent (непрерывный фьючерсный ряд) |
| **6** | Опционы Put/Call на фьючерс Brent (срез на один день) |


`data_clean.csv` — итоговая таблица

---

## Источники и цепочка происхождения данных

| Данные | API / эндпоинт | Первоисточник |
|---|---|---|
| КБД (a) | `cbr.ru/hd_base/zcyc_params/zcyc/?DateTo=ДД.ММ.ГГГГ` | Банк России (методика расчёта — ПАО «Московская Биржа») |
| Расписания ОФЗ (b) | `iss.moex.com/iss/securities/{SECID}/bondization` | НКО АО НРД / эмитент — Минфин РФ |
| Котировки ОФЗ (c) | `iss.moex.com/iss/history/.../markets/bonds` (доска TQOB) | Московская Биржа |
| Акции (d) | `iss.moex.com/iss/history/.../markets/shares` (доска TQBR) | Московская Биржа |
| Индексы (e) | `iss.moex.com/iss/history/.../markets/index` | Московская Биржа |
| Курсы валют (e) | `cbr.ru/scripts/XML_dynamic.asp` (USD=R01235, EUR=R01239) | Банк России (официальный курс) |
| Brent (e) | `iss.moex.com/iss/history/.../markets/forts` | Московская Биржа (срочный рынок FORTS) |
| Опционы (f) | `iss.moex.com/iss/history/.../markets/options` + `/securities/{SECID}` | Московская Биржа (срочный рынок FORTS) |
